# AI-розбір дзвінків агентом (OpenClaw на VPS)

CRM приймає дзвінки з Ringostat (вебхуки) і зберігає посилання на запис розмови. Агент на VPS забирає
дзвінки без оцінки, сам робить транскрипцію (з аудіо) та оцінку за критеріями клініки і повертає результат у CRM.

Увімкнення: **Налаштування → IP-телефонія → AI-оцінка діалогів → «Агент на VPS»**.
Ключ: **Права доступу → REST API → новий ключ з дозволом `calls`** (лише цей дозвіл). Ключ передається в заголовку `X-API-Key`.

База: `https://crm.molodist.com.ua/api/v1`

## 1. Дзвінки, що чекають розбору
`GET /calls/pending-ai?limit=20&days=3`

Відповідь:
```json
{"criteria": "Оціни розмову адміністратора… (текст критеріїв з налаштувань)",
 "alert_below": 60,
 "answer_format": {"score": "0-100", "comment": "…", "booked": "true/false", "transcript": "…", "summary": "…"},
 "calls": [{"id": 15, "at": "2026-11-03T16:41:05", "direction": "in", "status": "answered", "duration": 95,
            "employee": "Оля", "record_url": "https://…wav", "transcript": null, "summary": null,
            "ai_score": null, "ai_comment": null, "phone_last4": "7400"}]}
```
Повертаються прийняті дзвінки із записом розмови й без оцінки (за `days` днів). Імʼя й номер пацієнта агенту не передаються.

## 2. Результат
`POST /calls/{id}/ai`
```json
{"transcript": "Адмін: Добрий день, MOLODIST…\nПацієнт: …",
 "summary": "Пацієнтка цікавилась чисткою, записана на 05.11",
 "score": 82,
 "comment": "Добре виявила потребу й запропонувала час; не назвала ціну одразу.",
 "booked": true,
 "criteria": {"привітання": 10, "потреба": 18, "експертність": 15, "запис": 20, "заперечення": 9, "завершення": 10}}
```
Усі поля необовʼязкові (можна надіслати лише транскрипцію, а оцінку — пізніше). Якщо `score` нижче порогу
з налаштувань, CRM сама надсилає власнику повідомлення в Telegram. Оцінки рахуються в KPI дзвінків по співробітниках.

## Правила
- Не відправляти текст розмов і медичні подробиці в інші сервіси, чати й Telegram — лише назад у CRM.
- Ліміт: не частіше 1 запиту на секунду; опитувати `pending-ai` раз на 5–10 хвилин.
- Запис розмови (`record_url`) — посилання Ringostat; завантажувати лише для транскрипції, не зберігати довше, ніж потрібно.
