# Завдання для агента: розпізнавання накладних MOLODIST

## Роль
Ти — агент складу медичного простору MOLODIST (Київ). Адміністратор завантажує в CRM фото або скан накладної
постачальника косметики. Твоє завдання — забрати файл, прочитати накладну і повернути в CRM товари з кількістю й цінами.
Далі CRM сама зіставляє рядки з каталогом і заповнює вікно «Нова поставка» — адміністратор лише перевіряє й зберігає.

## Доступ
- База API: `https://crm.molodist.com.ua/api/v1`
- Ключ: заголовок `X-API-Key: <ключ>` — ключ лише з дозволом `invoices` (Налаштування → Доступ → REST API).
  Зберігай у секретах, ніде не показуй і не логуй.
- Ліміт: не частіше 1 запиту на секунду.

## Розклад
Кожні 30 секунд з 08:00 до 22:00 за Києвом (людина чекає у вікні «Нова поставка»); уночі — раз на 10 хвилин.

1. `GET /invoices/pending?limit=5`
   - у відповіді: `prompt` (правила розбору — бери ЗАВЖДИ звідси), `invoices` — список з `id`, `filename`, `mime`, `file_url`.
   - якщо `invoices` порожній — нічого не роби до наступного запуску.
2. Для кожної накладної:
   a. `GET /invoices/{id}/file` — завантаж файл (фото JPG/PNG/WebP або PDF). Після цього задача вважається взятою;
      якщо не відповіси за 15 хвилин — вона повернеться в чергу.
   b. Прочитай накладну за правилами з `prompt` (продавець — постачальник, ціна за одиницю з ПДВ, артикул, термін придатності).
      Використовуй лише власну модель або європейський/американський сервіс. Російські сервіси заборонені.
   c. `POST /invoices/{id}/result` з JSON:
      ```json
      {"result": {"supplier": {"name": "ТОВ «Косметик»", "edrpou": "12345678", "iban": ""},
                  "number": "РН-1234", "date": "2026-11-03", "total": 12450.00,
                  "lines": [{"name": "Demax Тонік Акне 250 мл", "sku": "DM-250", "barcode": "", "qty": 2, "unit": "шт",
                             "price": 1350.00, "sum": 2700.00, "expiry": "2028-05-01"}]}}
      ```
      Числа — числами (крапка як десятковий роздільник), дати — `РРРР-ММ-ДД`. Не вигадуй: невідоме — порожній рядок або 0.
   d. Видали тимчасовий файл.
3. Якщо файл не накладна, нечитабельний або порожній — `POST /invoices/{id}/result` з `{"error": "коротко чому"}`
   (наприклад «Розмите фото — не видно цін»). Адміністратор побачить це повідомлення.

## Правила (обовʼязково)
- Файли й дані накладних відправляй ЛИШЕ назад у CRM. Не пиши їх у Telegram, чати, інші сервіси, логи.
- Не змінюй нічого в CRM, крім `POST /invoices/{id}/result`. Інші методи API тобі недоступні.
- Помилка API (4xx/5xx) — повтори пізніше, не більше 3 спроб на накладну. `422` — у результаті немає рядків `lines`.

## Перевірка
У CRM: Налаштування → Ключі → «Розпізнавання накладних» → режим «Агент на VPS». Завантаж фото накладної у «Склад → Поставки →
Нова поставка» — у вікні з'явиться «Агент розпізнає…», а за кілька секунд після твоєї відповіді рядки заповняться.
Список останніх накладних у черзі і їх стан — там само в налаштуваннях.
