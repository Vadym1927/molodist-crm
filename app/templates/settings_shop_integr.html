Відгуки з Google Карт

Рейтинг і останні відгуки про MOLODIST з Google Карт — блок довіри на головній і в «Контактах». Потрібен ключ Google Places API (Google Cloud → API і сервіси → увімкнути «Places API (New)» → Облікові дані → Ключ API, обмежити ключ лише Places API) і Place ID медичного простору (developers.google.com/maps/documentation/places/web-service/place-id). Оновлення двічі на добу — у межах безкоштовного ліміту Google. Зірок у пошуку ці відгуки не дають (правило Google), але додають довіри на сторінці.
