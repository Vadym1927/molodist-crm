Налаштування

Як запустити домен {{ c.hosts[0] if c.hosts else 'new.molodist.com.ua' }}

  1. DNS: у панелі, де керуєте molodist.com.ua, додайте A-запис {{ (c.hosts[0] if c.hosts else 'new.molodist.com.ua').split('.')[0] }} → IP нашого VPS (той самий, що в crm.molodist.com.ua).
  2. Nginx на VPS (робить адміністратор сервера / агент OpenClaw): новий server-блок для домену з proxy_pass http://127.0.0.1:8010; і proxy_set_header Host $host; proxy_set_header X-Real-IP $remote_addr;, потім certbot --nginx -d {{ c.hosts[0] if c.hosts else 'new.molodist.com.ua' }}.
  3. Відкрийте домен — має зʼявитися сторінка напрямків. Тоді в Tilda на старих сторінках ставимо переадресацію на нові.
  4. Tag Manager: замініть код тегу «MOLODIST CRM v2» на свіжий з Налаштування → Google Ads і опублікуйте. Новий тег пропускає сторінки на VPS (їхні форми й кліки CRM приймає напряму), інакше заявка прийде двічі (друга — коментарем у тому ж зверненні).
